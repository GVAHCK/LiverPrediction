# Liverify — Liver Disease Prediction System

Liverify is a full-stack Machine Learning application built with **Flask** and **Scikit-Learn** (K-Nearest Neighbors Classifier) that analyzes clinical liver patient laboratory results to assess and predict the risk of liver disease.

---

## Architecture Overview

- **Backend**: Python Flask 2.0.2 REST/MVC application.
- **Machine Learning**: Scikit-Learn `KNeighborsClassifier` trained on the Indian Liver Patient Dataset (`indian_liver_patient.csv`), featuring z-score feature normalization (`StandardScaler`), missing-value imputation, and one-hot encoding for categorical variables.
- **Frontend**: Responsive Jinja2 templates styled with Tailwind CSS, supporting interactive lab value validation, report generation, and instant printing.
- **Configuration**: 12-factor `.env` environment configuration via `python-dotenv`.
- **Testing**: Automated unit and integration test suite using `pytest`.

---

## Prerequisites

- **Python**: 3.8 (recommended for exact binary wheel compatibility) or compatible CPython runtime.
- **Package Manager**: [`uv`](https://docs.astral.sh/uv/) (fastest) or standard `pip`.

## Quickstart

### 1. Automated Start (Recommended)

From the project directory, run:

**PowerShell**:
```powershell
.\run.ps1
```

**Command Prompt / Windows CMD**:
```cmd
run.bat
```

These scripts automatically initialize the virtual environment, install pinned dependencies, and launch the server on `http://127.0.0.1:9000`.

---

### 2. Manual Setup

1. **Create and activate a virtual environment**:
   ```bash
   uv venv .venv --python 3.8
   # Windows PowerShell
   .venv\Scripts\Activate.ps1
   # Or Windows CMD
   .venv\Scripts\activate.bat
   ```

2. **Install dependencies**:
   ```bash
   uv pip install -r requirements.txt
   ```

3. **Configure environment variables**:
   ```bash
   copy .env.example .env
   ```

4. **Run the server**:
   ```bash
   python server.py
   ```

5. **Access the application**:
   Open [http://127.0.0.1:9000](http://127.0.0.1:9000) in your web browser.

## Running the Automated Test Suite

To run all unit and integration tests:

```bash
pytest -v
```

All 14 tests verify endpoint availability, template rendering, ML model caching, feature scaling alignment, input validation (empty fields, non-numeric strings, negative lab values, out-of-range age), and clinical risk predictions.

## Stopping and Restarting

### Stop the Server
In the terminal where the server is running, press:
```bash
Ctrl + C
```

Or from PowerShell, terminate any background process bound to port 9000:
```powershell
Get-Process python -ErrorAction SilentlyContinue | Where-Object { $_.Path -like "*Liver-Predictions*" } | Stop-Process -Force
```

### Restart the Server
```powershell
.\run.ps1
```
